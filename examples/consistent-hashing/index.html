Keys and servers are hashed onto the same ring. Each key belongs to the first server clockwise from it, and takes that server's colour. Add a server and only the keys in the arc it takes over change colour. With plain hash % n, changing the number of servers reshuffles almost every key, so almost every cache misses at once.

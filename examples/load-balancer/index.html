Three servers, three speeds: fast, medium and slow. Round robin deals requests out evenly, so the slow server fills up and starts dropping work while the fast one sits idle. Switch to least busy and the dispatcher sends each request to the server with the shortest pile. Then fail a server and watch the others absorb its traffic.

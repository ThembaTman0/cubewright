cubewright github

System design, playable.

Each concept is a little machine made of cubes. Watch it run, then push it until it breaks: burst the rate limiter, overload a server, flood the queue, thrash the cache.

Embed one

Drop any machine into a blog post or docs page:

Make your own

Cubewright is also a Claude skill. Ask it to explain an idea, and it assembles a new machine from the same parts.
